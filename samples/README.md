# Sample decks

Five small Anki packages to try Kardo with. Download one (click the file, then **Download raw file**) and import it
from Kardo's settings screen, or load them all at once:

```sh
python3 server.py import samples/*.apkg
```

| Deck | Cards | Shows off |
|---|---|---|
| [`geography-flags-capitals.apkg`](geography-flags-capitals.apkg) | 62 | Images in cards, two templates per note (flag → country, country → capital), tags per continent |
| [`spanish-a1-vocabulary.apkg`](spanish-a1-vocabulary.apkg) | 72 | Forward and reverse cards, custom fonts and colours, part-of-speech badges, example sentences |
| [`japanese-hiragana.apkg`](japanese-hiragana.apkg) | 46 | Non-Latin script, large type, a gradient card style, conditional template sections |
| [`cell-biology-cloze.apkg`](cell-biology-cloze.apkg) | 37 | Cloze deletions, including notes with up to four gaps |
| [`git-essentials.apkg`](git-essentials.apkg) | 20 | Code blocks and inline code on a dark card style |

They are generated by [`scripts/make_samples.py`](../scripts/make_samples.py) with
[genanki](https://github.com/kerrickstaley/genanki). The content is original and MIT-licensed like the rest of Kardo.
