# Importing decks

Open Kardo, tap the ⚙️ gear, choose one or more files and tap **Import**. On a phone the picker can read
from Files, iCloud Drive, Google Drive or anywhere else the system exposes. Progress is stored on the server, so
it doesn't matter which device you import from.

From a shell:

```sh
python3 server.py import deck.apkg more.csv            # uses KARDO_DATA
docker exec kardo python /app/server.py import /data/deck.apkg
```

Over HTTP (see the [API](api.md)):

```sh
curl -X POST --data-binary @deck.apkg "http://kestrel:8484/api/import?filename=deck.apkg"
```

## Anki packages (`.apkg`)

Kardo reads the package format Anki uses for deck exports (`collection.anki21` or `collection.anki2` inside the zip).

| Anki feature | Supported | Notes |
|---|---|---|
| Decks and subdecks (`Parent::Child`) | ✅ | Recreated as a tree; filtered decks import into their original deck |
| Note types with several card templates | ✅ | Each template becomes its own card |
| Note-type CSS | ✅ | Scoped to the card with a shadow DOM |
| `{{Field}}`, `{{FrontSide}}`, `{{Tags}}`, `{{Deck}}`, `{{Subdeck}}` | ✅ | |
| `{{#Field}}…{{/Field}}` and `{{^Field}}…{{/Field}}` | ✅ | Nested sections too |
| `{{cloze:Field}}` with hints (`{{c1::answer::hint}}`) | ✅ | One card per cloze number |
| `{{text:Field}}` | ✅ | |
| Images, audio, video in fields | ✅ | Files go to `/data/media` |
| `[sound:file.mp3]` | ✅ | Becomes an audio player |
| `.nightMode` / `.night_mode` CSS | ✅ | Set in dark mode, so decks can style themselves |
| Tags, including hierarchical `a::b` tags | ✅ | Filter study by tag |
| New-card order from the deck | ✅ | |
| `{{type:Field}}` (type the answer) | ➖ | Hidden; grade yourself as usual |
| `{{tts:…}}` | ➖ | Hidden |
| Scheduling history from Anki | ➖ | Cards start as new in Kardo |
| JavaScript in templates | ❌ | `<script>` elements are not run |
| Image occlusion | ❌ | |

### "This package uses the newest export format"

Recent Anki versions can write a zstd-compressed collection (`collection.anki21b`) that needs extra libraries to
read. In Anki desktop, use **File → Export**, choose *Anki Deck Package*, and tick
**Support older Anki versions**. The result imports into Kardo with nothing lost.

### `.colpkg`

A `.colpkg` is a backup of a whole Anki profile, not a deck. Export the decks you want as `.apkg` instead.

## CSV, TSV and TXT

The first column is the front and the second is the back. Kardo sniffs the separator (tab, semicolon or comma)
from the first line, and treats the text as HTML if it contains tags.

```csv
What is the capital of France?,Paris
"Multi-line, quoted",Works too
```

The deck name defaults to the file name (`world_capitals.csv` → *world capitals*).

### Header lines

Kardo understands the header lines Anki writes in its text exports, so an Anki "Notes in Plain Text" export
imports directly. Put them at the very top of the file:

| Header | Example | Effect |
|---|---|---|
| `#separator:` | `#separator:tab` | `tab`, `comma`, `semicolon`, `pipe`, `colon`, `space`, or a literal character |
| `#html:` | `#html:false` | `false` escapes `<` and `>` and turns line breaks into `<br>` |
| `#columns:` | `#columns:Front	Back	Tags` | Names columns; `Tags` and `Deck` columns are recognised by name |
| `#deck:` | `#deck:Spanish::Verbs` | Deck for every row (subdecks with `::`) |
| `#tags column:` | `#tags column:3` | 1-based column holding space-separated tags |
| `#deck column:` | `#deck column:4` | 1-based column holding each row's deck |

Example:

```text
#separator:tab
#html:false
#columns:Front	Back	Tags	Deck
#deck:Geography
France	Paris	europe capitals	Geography::Europe
Japan	Tokyo	asia capitals	Geography::Asia
```

## Re-importing and updating decks

Every card keeps a stable id: the Anki note's GUID plus the card number, or for CSV a hash of the deck and the
front text. When you import a file again:

- cards that already exist get their **text, styling, deck and tags updated**, and keep their full review history and schedule;
- new cards are added at the end of the new-card queue;
- cards that are no longer in the file are **left alone**, so nothing is deleted by accident. Delete a deck from its overview screen if you want a clean slate.

For CSV decks, changing a card's front text makes it a new card, because the front is part of its id.

## Troubleshooting

| Problem | What to do |
|---|---|
| "That file is not a valid .apkg (zip) package" | The download is incomplete or it isn't an Anki package. Re-download or re-export |
| "newest export format" | Re-export with *Support older Anki versions* ticked |
| Images missing | The deck was exported without media. In Anki, tick *Include media* |
| A card looks different from Anki | Open an issue with the note type's templates and CSS (or a one-note `.apkg`) |
| Upload fails behind a proxy (413) | Raise the proxy's body size limit; Kardo accepts up to 300 MB |
